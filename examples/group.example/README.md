# Пример группы

`vocab.json` — шаблон словаря с выдуманными участниками (Анна, Борис, Вера, Глеб).

Как использовать:
1. Создайте каталог `<папка данных>\groups\<имя-группы>\` (папку данных показывает `get_settings` → `data_dir`).
2. Скопируйте туда `vocab.json`, поменяйте `group` на то же имя, внесите своих участников и термины.
3. Голосовой профиль (`voices.json`) появится рядом сам, когда вы подтвердите имена в расшифровках.

Формат полей описан в начале `vocab.py`.
