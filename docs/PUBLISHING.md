# Передача: подготовка к публикации на GitHub

Состояние кода (ТЗ «отделить персональные данные от кода» выполнено, публикация и git не трогались):

- **Данные вне программы.** Всё личное (голосовые профили, словари групп, настройки, задачи) лежит в папке данных:
  `RUS_TRANSCRIBER_DATA`, иначе `%APPDATA%\rus-transcriber-data`. Код пишет только в `cache\` и `.venv\` программы.
  Раскладка: `config.json` (только отличия от умолчаний), `groups\<группа>\{vocab,voices}.json`, `jobs\`, `bench\`.
  Все пути — в `paths.py`, настройки — `settings.py`, перенос со старой раскладки — `migrate.py`.
- **Слои:** `core.py` (ядро без MCP), `server.py` (MCP), `rt.py` (командная строка); опасные действия подтверждает
  человек (`confirm.py`, окно или `rt.py approve`).
- **Перенос и обслуживание:** `data_io.py` (библиотека) / `rt.py` / MCP-инструменты `export_group`, `import_group`, `delete_group`,
  `cleanup_jobs`. Установщик: `-DataDir`, `-Uninstall` отдельно спрашивает про данные (по умолчанию не удалять).
- **Имена реальной группы заменены** на вымышленные (Анна, Борис, Вера, Глеб, «Вереск»); пример словаря —
  `examples\group.example\`. Реального `vocab.json`, `config.json`, профилей в дереве нет; есть `config.example.json`.
- **Защита от возврата:** `.gitignore`; `python tools\check_repo.py` (и `--staged`; хук — `tools\pre-commit`);
  тесты `python -m unittest discover -s tests` (89 проверок: ядро, слои, подтверждение, перенос данных, оценка качества);
  оценка качества на реальных записях — `tools\eval_quality.py` (случаи и эталоны хранятся в папке данных).

## Что сделать перед первым коммитом
1. На компьютере владельца (где есть папка данных) выполнить `python tools\check_repo.py`: код возврата **0** —
   чисто, **2** — список запрещённых слов пуст (проверка слов не выполнена), **1** — есть нарушения.
   Список запрещённых слов собирается из локальных данных (`groups\*\vocab.json`, `voices.json`) и необязательных
   `forbidden_words.txt` / `allow_words.txt` в папке данных — в репозитории его нет и быть не должно.
2. Установить хук: `copy tools\pre-commit .git\hooks\pre-commit`.
3. `git init` делать в папке с кодом, у которой рядом нет `groups\`, `jobs\`, `cache\`, `.venv\`: `.gitignore` их
   исключает, но проверьте `git status` до первого `git add`.
4. Не коммитить архивы `export_group` и резервные папки `_backup*`, `_deleted` (они в `.gitignore`).

## Известные ограничения
- В Store-версии Claude Desktop `%APPDATA%` и `%LOCALAPPDATA%` подменяются скрытой папкой пакета; путь данных строится
  от домашней папки и записывается установщиком в `RUS_TRANSCRIBER_DATA`. Проверено: файлы задач видны в реальной
  `%APPDATA%\rus-transcriber-data`.
- После импорта профиля на другой компьютер учтённые записи хранятся под именем файла (без пути); при переучивании
  по тем же расшифровкам они могут быть учтены повторно.
