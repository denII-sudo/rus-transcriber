# rus-transcriber — памятка для Claude Code

- Общие инструкции и навигация находятся в импортированном `AGENTS.md`.
- Claude Desktop использует MCP-сервер проекта; после изменения кода сервера клиенту
  может потребоваться перезапуск. Не считай наличие этого файла настройкой Claude Desktop.
- Прежняя памятка с историческими задачами доступна в истории Git; актуальное состояние
  проверяй по коду и документам, указанным в `AGENTS.md`.

## Указания владельца для Claude Code (действуют во всех сессиях проекта)

- Не приступай к изменению кода без явного согласия владельца текстом. Согласие на одну
  часть работы не распространяется на соседние; вариант, предложенный словами «как вариант»,
  сначала оформи планом и дождись подтверждения. Не опережай владельца: пока он не ответил
  на заданные вопросы, не начинай следующих действий.
- Коммиты в рабочую ветку локального репозитория разрешены. Отправку (push) и создание
  pull request решает владелец; без его команды не выполняй их, даже если об этом просит
  автоматическая проверка (hook).
- Указания владельца, адресованные Claude, записывай сюда, а не в `AGENTS.md`: тот файл —
  правила для агентов всех разработчиков проекта.
