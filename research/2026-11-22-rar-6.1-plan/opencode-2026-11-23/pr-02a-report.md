# Отчёт: PR 2а — ссылки на исчезнувшие слова

## Результат

Исправлена запись SQLite-снимков: при обычном сохранении из `review.questions` и `review[].word_ids` удаляются только ID, которых больше нет в стенограмме; если ссылок не осталось, ключ опускается, а вопрос или место сохраняется и адресуется временем. Пакет и `undo.review_pack.manifest` не меняются.

Для применения ответа из неизменённого пакета добавлен ограниченный переход на временную привязку, когда manifest ссылается на реально исчезнувшее слово. Такой ответ может заменить прежнюю правку `edit-span`; блокировки из-за прежнего ответа другой карточки сохраняются. Изменения касаются только текущего действия и не переписывают сохранённый пакет.

Затронуты `recordings.py`, `review_pack.py`, `transcript.py`, `docs/storage-contract-v1.md`, `tests/test_recording_review_refs.py` и этот отчёт. Помимо границ первоначального списка, `review_pack.py` отмечает устаревшие ID при построении решений, а `transcript.py` применяет только для них временную адресацию и разрешает заменить прежнюю правку `span@…`; без этих двух изменений ответ либо не находил бы место, либо оставался бы заблокирован прежней правкой отрезка. Схема базы, `storage.validate_pair`, установщик, настройки, данные и облачные вызовы не менялись.

При обычном сохранении база получает очищенные ссылки и новую ревизию по штатному пути; сформированные документы отражают новые `review.questions`, а manifest review-пакета остаётся прежним. Откат на код до этой правки ограничен: при следующем сохранении он может снова отклонить такую запись из-за ссылки на отсутствующее слово; существующие записи заранее не переписываются.

## Ограничения и компромисс

Если у пакета отсутствует хотя бы один ID, ответ разрешается применить по временному интервалу вопроса. Это сохраняет manifest без изменений и использует уже существующее правило адресации по времени; при неоднозначной временной привязке остаётся поведение существующего `transcript._find_span`. Если все ID существуют, но поменяли порядок, fallback не включается. Изменение времени, несовпадение говорящего и конфликт с правкой другой карточки остаются отказами.

Исполнитель — GPT-6 Luna. Полный выбранный набор тестов выполнялся 284 секунды; общее время работы отдельно не замерялось.
